# SE2 Review App

## Running
```
npm install
npm run dev
```
Then open http://localhost:5173/

## Functionality
App has two functions:

1. Listing employees  
    a. employees can be sorted alphabetically
2. Counter  
    a. every click on Increase button should raise counter by 1
